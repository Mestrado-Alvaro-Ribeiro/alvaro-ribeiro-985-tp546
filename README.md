# Estacionamentos inteligentes com RSSF

Relatório acadêmico sobre o uso de uma Rede de Sensores Sem Fio (RSSF/WSN) para detectar vagas livres e informar motoristas por aplicativo.

## Compilação

Com uma distribuição LaTeX instalada, execute:

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

O arquivo final será `main.pdf`. O diagrama está incorporado no próprio `main.tex`.

## Organização

- `main.tex`: relatório completo, em português;
- `referencias.bib`: referências científicas utilizadas;
- `artigos/`: espaço para adicionar os PDFs dos artigos antes de publicar no GitHub;
- `materiais/`: espaço para slides, imagens ou outros anexos.

## Referências científicas

Os artigos utilizados estão listados em `referencias.bib` com DOI. Recomenda-se baixar os PDFs diretamente dos repositórios das editoras ou bibliotecas institucionais, respeitando as licenças, e colocá-los em `artigos/`.
